Lean81 1.0 adds practical laptop tuning and CPU, RAM and disk diagnostics in a small native Windows EXE.

Download **Lean81-1.0.0-portable.zip**, extract it and open **Lean81.exe**. A standalone EXE is attached too. No Python, installer, browser engine, account or permanent service is required.

- **Quick tune:** choose unused features, build a review and apply with saved originals. Includes a browser/cloud-gaming preset.
- **13 optional services:** new scanner, portable-device synchronization, error-reporting and moved-file link-tracking choices; usage answers and dependencies remain enforced.
- **Desktop effects:** optionally reduce taskbar animations, desktop Peek and icon-label shadows. Restore exact previous DWORDs or their original absence. Sign out and back in to refresh Explorer.
- **Resource capture:** CPU/RAM/disk chart, disk throughput/queue, page-ins, commit usage, kernel CPU and paged/nonpaged pools.
- **Process leaders:** sort CPU, working-set RAM, private memory and read/write I/O. Memory-heavy apps remain visible even with no CPU activity.
- **Better evidence:** qualified findings, resource metrics and coverage in local HTML/CSV/JSONL, plus disk baseline differences only for complete disk coverage.
- **Upgrade support:** preserve ProgramData\Lean81 and LocalAppData\Lean81. Receipts, preferences and aggregate history from 0.1–0.3 remain supported; new answers default to kept.

Changes still require a review, protected backup and current-state checks. Recovery stops for independent edits. Networking, security, input, core OS and update services remain protected. No RAM cleaner, blanket process killing or pagefile/kernel tweaks are included.

Process I/O includes network/device operations and is not per-process disk utilization. Disk readings are aggregate across disks. Missing counters remain unknown. Two-second sampling can miss short spikes. No particular speed improvement is guaranteed.

**Unsigned release targeting Windows 8.1 / .NET Framework 4.5.1.** Automated compilation, isolated policy/transaction/resource tests, disposable native Windows fixtures, real resource capture and a read-only x86 resource-layout probe, GUI smoke/screenshots and report/browser checks run on newer Windows. Physical Windows 8.1 testing remains pending. Desktop-setting writes are tested in memory; native fixtures inspect those settings without changing them.
