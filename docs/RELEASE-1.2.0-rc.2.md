Lean81 RC2 gives the desktop app a coherent charcoal-and-lime interface while keeping the same reviewed tuning and recovery workflow.

- **Grouped Deep tune:** starting-point cards, Windows/Devices/Sharing/Apps feature switches and a live proposal summary. KEEP and UNUSED states have text as well as color. Editing a preset marks the choices as custom.
- **Snapshot dashboard:** last observed CPU, available RAM and storage capacity, with direct tuning and running-app actions. Missing CPU data says On demand. Values are labelled snapshots, not a permanent background monitor.
- **A consistent desktop:** drawn icons, grouped navigation, matching buttons/tabs/tables/charts/review dialogs, clearer page titles and a footer that hides an empty review action.
- **Lightweight rendering:** native C# 5 / .NET Framework 4.5.1, geometry-based icons and event-driven drawing. No web view, downloaded fonts/assets or animation loop is added.
- **Usability checks:** native accessibility default actions, preset-card/custom-choice behavior, grouped navigation and screenshots at two window sizes. Reviewed configuration changes, app closure and conflict-aware recovery remain intact.

Extract the portable ZIP and open Lean81.exe. Start on Dashboard, open Deep tune, pick a starting point and keep every feature you need. Review tune refreshes the scan and shows the actual installed changes before applying them. Keep existing recovery folders when upgrading; reopen closed apps manually.

This is a preview. Stable 1.1 remains available. The EXE is unsigned and physical Windows 8.1 hardware, display-scaling, high-contrast and screen-reader validation remains pending. Short resource observations are not a performance benchmark or proof of a speed increase.
