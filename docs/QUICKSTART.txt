Lean81 1.2.0-rc.1 - HamWebDevs - release candidate

ACTIVELY REDUCE BACKGROUND LOAD
1. Extract the portable ZIP and open Lean81.exe.
2. In Deep tune, click Maximum reduction.
3. Check features you need to keep. The preset assumes no printing, Bluetooth,
   indexing, Superfetch, TV, sync, chat or local game launchers. Compatibility
   assistance and Windows themes stay enabled unless you choose otherwise.
4. Choose Review deep tune. Read Settings and Close apps now. Uncheck apps
   you need, or Keep all apps. Normal close is the default; force close is
   an explicit option for tray/helpers and may lose app work. Apply the review.
   If administrator permission is needed, use the same account and build the
   review again after the elevated scan. Nothing applies just from a preset.

Services stop now and stay disabled. Providers are stopped after their
reviewed dependents. Startup entries/shortcuts/tasks stop future launches.
Windows networking, security, core services and Windows Update are protected.

FREE RESOURCES NOW
Deep tune can close reviewed companions in unused categories after settings
finish. If settings fail, closure is skipped. Running apps also lets you
select companions you do not need and Close selected separately.
A normal close request is the default. Force close is a separate option for
tray/helper apps that remain running. Closing can interrupt sync, downloads,
music, calls or unsaved app state. Browsers and foreground families are kept.
Closed apps are reopened manually; their work is not restored by Recovery.

UNDO A TUNE
Use Tune result > Restore this tune, or open Recovery as administrator under
the same account and choose Restore tune group for a Deep tune receipt.
Independent edits stop recovery rather than being overwritten. Partial
failures are recorded; read the receipt and RECOVERY.md before retrying.
Keep ProgramData\Lean81, including startup-backups. Do not share private
receipts: they can contain commands, shortcut data and file permissions.

OPTIONAL POWER PLAN
High performance is an opt-in existing Windows plan. Mains power is required
when applying it. It can use more energy and heat and stays active until
changed or restored. Lean81 does not run a resident power-plan watcher.

NO RECORDING REQUIRED
Optional short CPU/RAM/disk checks run before and after tuning, taking about
18 extra seconds. Turn them off in the review to tune without observations.
Tune result shows actual action outcomes and short observed differences;
they vary with workload and are not a speed benchmark. Missing readings are
unavailable, not zero. The result stays in memory; recovery receipts persist.
Everything above happens inside Lean81. Resource capture, reports and
comparison tools remain available if you want to investigate a remaining
slowdown; no external recorder or analysis app is required.

UPGRADE
Close the old version, extract the new ZIP into a new folder and open it.
Keep ProgramData\Lean81 and LocalAppData\Lean81. Existing 0.1-1.1 data works;
new feature answers default to kept when missing from older preferences.

Windows 8.1 / .NET Framework 4.5.1 target; no Python or bundled browser.
Unsigned EXE. Automated tests use newer Windows; physical Windows 8.1 tests
remain pending. No particular speed increase is guaranteed.
