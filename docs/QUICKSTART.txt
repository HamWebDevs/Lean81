Lean81 0.2.0 preview - HamWebDevs

GET STARTED
1. Extract the portable ZIP and open Lean81.exe.
2. Choose Quick setup. Keep features checked if you use them or are unsure.
3. Review the matching choices, select specific items, then Review changes.

Presets only fill usage answers. Nothing is disabled automatically. Scan,
capture, compare and export without admin. Enabling changes opens a fresh
administrator scan under the same Windows account; your answers are remembered,
and you choose items again before applying. You can save a review as text.

MEASURE THE RESULT
Open CPU capture and name the activity (for example, Browsing).
Capture 30 seconds of normal use. In Saved results & baseline, select the
result and choose Use as baseline. After changes, repeat the same activity,
duration and power source. Select the new result and Compare selected.
Mismatched or incomplete runs are explained rather than given a speed score.
Up to 12 aggregate results are saved locally; the baseline is retained.

MORE FEATURES
Recommendations: next steps based on your scan and observations.
Device & storage: CPU, RAM, uptime, battery/power and fixed-drive free space.
Installed apps: filter by name or publisher; use the normal Windows uninstaller.
Export report: local HTML, with software names omitted by default.
Export trace: ReclaimLab JSONL or CSV; process names omitted by default.
Help & tools: built-in guidance and nine fixed Windows tool shortcuts.
Recovery: check saved states without writes, or restore exact original settings.

KEEP YOUR RECOVERY DATA
Keep C:\ProgramData\Lean81: it contains original settings. Do not share its
private receipt JSON; startup commands may contain personal information.
Preferences and aggregate history are in LocalAppData\Lean81\workspace.json.
If saving fails, Lean81 shows that choices/results remain in this session.

Windows 8.1 includes the target .NET Framework 4.5.1. No Python, browser
engine, installer, runtime download, telemetry or permanent service is needed.
This is an unsigned preview. Physical Windows 8.1 validation is pending;
automated tests run on newer Windows. See COMPATIBILITY.md and FEATURES.md.

Upgrade: extract the new version into a new folder. Close the previous app.
Keep ProgramData\Lean81 and LocalAppData\Lean81. Version 0.1 recovery receipts
remain supported. Demo: Lean81.exe --demo (synthetic; no system/settings writes).
