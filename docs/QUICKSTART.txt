Lean81 1.0.0 - HamWebDevs

QUICK TUNE YOUR LAPTOP
1. Extract Lean81-1.0.0-portable.zip and open Lean81.exe.
2. Open Quick tune. Try Browser / cloud gaming laptop, then check every answer.
3. Keep features checked if you use them or are unsure. Untick indexed search
   or Superfetch only if you want to try those particular tradeoffs.
4. Optionally include desktop effects, then choose Build my review.
5. Read the changes and apply. Original settings are saved first. If Windows
   asks for administrator permission, build the review again after the rescan.
6. Review recognized Startup apps separately to stop unnecessary sign-in apps.

Services with enabled dependents stay protected. Nothing is disabled merely
by selecting a preset. Reduced desktop effects may need sign-out/sign-in.

FIND CPU, RAM AND DISK PRESSURE
Open Resource capture and record 30-120 seconds during the slowdown.
Teal = CPU, blue = physical RAM in use, amber = aggregate disk busy.
Open Memory, disk & processes to sort CPU/RAM/private-memory/I/O leaders
and read commit usage, kernel pools, disk queue and page-in observations.
Unknown counters stay unknown. Process I/O includes network and device
operations, not just disk; use Resource Monitor for detailed attribution.

COMPARE BEFORE AND AFTER
In Saved results & baseline, select a capture and choose Use as baseline.
After changes, repeat the same activity, duration and power source. Compare
a different result. Disk differences require complete disk sample coverage.
Up to 12 aggregate results are saved; process names and PIDs are not in history.

UNDO CHANGES
Open Recovery as administrator under the same Windows account. Check the
saved states, select a receipt and Restore selected receipt. Independent
changes stop recovery rather than being overwritten. See RECOVERY.md.
Keep ProgramData\Lean81 for original settings; do not share private receipts.
Keep LocalAppData\Lean81 for preferences/history. Existing 0.1-0.3 data works.

MORE
Desktop effects: three reversible Explorer choices.
Installed apps: filter software, then use Windows' normal uninstaller.
Device & storage: hardware, power and available fixed-drive capacity.
Export report: printable offline HTML; baseline/history are optional.
Export trace: JSONL or CSV; process names are omitted by default.
Help & tools: fixed shortcuts including Task Manager and Resource Monitor.

No Python, installer, bundled browser, RAM cleaner or permanent service.
Windows 8.1 / .NET Framework 4.5.1 target. The EXE is unsigned. Automated
checks use newer Windows; physical Windows 8.1 testing remains pending.
No particular speed improvement is guaranteed. See COMPATIBILITY.md.

Source and releases: https://github.com/HamWebDevs/Lean81
Demo: Lean81.exe --demo (synthetic data; no Windows settings changed).
