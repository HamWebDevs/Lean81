Lean81 0.3.0 preview adds a clearer, printable laptop report.

Download **Lean81-0.3.0-portable.zip**, extract it and open **Lean81.exe**. A standalone EXE is also included. No Python, installer, browser engine or permanent service is required.

- Responsive report cards, next steps, device/storage observations and background inventory coverage.
- Export any selected saved CPU result with the retained baseline. Condition mismatches are explained; differences are calculated only for compatible recorded observations.
- Optional aggregate history, up to 12 results. Workload labels, machine identifiers, paths, commands, task XML and recovery receipts are withheld. Software names remain a separate opt-in.
- Current-result completion, sample coverage, observed duration, power and observer CPU cost. Scan, device and capture dates are clearly separate.
- Offline document with accessible tables, print layout, encoded text and no scripts or external resources.

Validation includes isolated transaction/policy/report checks, disposable native Windows fixtures, and real Windows Forms smoke/screenshots. Generated report variants cover compatible, mismatched and missing captures. Automated Windows testing uses newer Windows; physical Windows 8.1 validation is pending.

**Unsigned preview targeting Windows 8.1 / .NET Framework 4.5.1.** CPU observations do not prove causality, and no performance gain is promised. Read the feature/privacy and recovery guides. Preserve ProgramData\Lean81 and LocalAppData\Lean81 when upgrading; existing receipts and summaries remain supported.
