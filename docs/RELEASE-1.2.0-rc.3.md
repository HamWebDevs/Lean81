Lean81 RC3 adds precise control to Deep tune: choose individual settings and remember the items you want to keep.

- **Individual setting checkboxes:** review each service, startup entry, scheduled task, desktop effect and power choice. Each row shows when its change takes effect; select it for the exact target and tradeoff.
- **Saved keep list:** unchecked settings start kept on the next deep tune. Recheck individual items to include them again, use feature choices to reselect the current proposal, or clear saved keeps from Deep tune. Presets retain your keep list.
- **Dependency-aware keeps:** retaining a dependent also retains its required service providers, transitively. The selected count and explanations follow the actual remaining actions.
- **Preferences without tuning:** keep all settings and apps, then Save keep list. Cancel discards staged exclusions. Keep choices do not restore already-applied settings; Recovery handles that.
- **Existing recovery and app protection:** selected settings still use fresh-state policy checks and exact saved recovery records. Companion closure retains its separate normal/force review, same-user identity checks and foreground protection.

Extract the portable ZIP and open Lean81.exe. Deep tune > Review tune > Settings now provides individual checkboxes. Keep your existing recovery folders when upgrading. No Python, installer, browser runtime, resident service or telemetry is added.

This is a preview; stable 1.1 remains available. The native EXE is unsigned. Automated checks run on modern Windows; physical Windows 8.1 hardware, display-scaling, high-contrast and screen-reader validation remains pending. Short resource observations do not establish a speed improvement.
