Lean81 0.2 makes the Windows laptop workbench easier to use and adds substantial diagnostics while keeping the small C# executable and reversible change engine.

Download **Lean81-0.2.0-portable.zip**, extract it and open **Lean81.exe**. No Python, bundled browser, installer, account or permanent service is needed.

New in this preview:

- Guided quick setup, three usage presets and remembered answers. Presets fill answers only; they never apply settings.
- Recommendations, selectable-only inventory filters, kept-item explanations, an app search and a select-unused-services review shortcut.
- Time-weighted CPU summaries, up to 12 saved results and a retained baseline. Comparisons check workload, power, duration, coverage, completeness and hardware before presenting differences.
- Device/RAM/uptime/power/battery and fixed-drive capacity snapshots, with Windows Disk Cleanup access.
- Standalone local HTML reports and spreadsheet CSV capture export. Software/process names stay opt-in; HTML is encoded and CSV strings are protected against formula-leading names.
- Non-admin review, saveable text reviews and recovery-state assessments that make no system-setting changes.
- An in-app help hub and nine fixed Windows system-tool shortcuts.
- Eleven pages rendered at normal and small window sizes, setup/review cancellation checks, baseline comparison and checkbox/filter/protection interaction checks.

Keep `%ProgramData%\Lean81` when upgrading: existing 0.1 recovery receipts remain supported. Preferences and aggregate history live under `%LocalAppData%\Lean81`. Recovery receipts can contain private startup commands and should not be shared.

This is an **unsigned preview targeting Windows 8.1 and .NET Framework 4.5.1**. Automated validation uses newer Windows; physical Windows 8.1 testing is still pending. No performance improvement is promised without measurements on your laptop. Capacity is not a disk-health assessment, and matching capture labels do not prove matching workloads or causality.

Security, networking, core OS and update services remain outside the service allowlist. Read the included quick start, feature guide, privacy guide, compatibility and recovery documentation.
