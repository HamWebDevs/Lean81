Lean81 1.1 shifts the main workflow to actively reducing background load. No recording or external analysis app is required.

Download **Lean81-1.1.0-portable.zip**, extract it and open **Lean81.exe**. The standalone EXE is also attached.

- **Deep tune:** maximum-reduction browser/cloud-gaming preset, reviewed recognized startup/task choices and 26 optional service choices. Services stop now and remain disabled.
- **Dependency handling:** stop reviewed dependents before providers, retain one tune group and restore providers first. Enabled dependents outside the review remain protected.
- **Startup-folder control:** user/common `.lnk` and `.url` shortcuts move to protected same-volume backups. Recovery restores original bytes, timestamps, ownership and permission rules; new shortcuts are never overwritten.
- **Running apps:** close selected recognized launcher/sync/chat/music companions inside Lean81. Normal close is the default; force close is explicit. Fresh user/session/PID/creation-time, critical-process and foreground-family checks protect unrelated processes. Closing can interrupt app work; reopen closed apps manually.
- **Power plan:** optional existing High performance scheme, applied only on mains. The prior scheme is saved; the selected plan stays active until changed/restored and can use more heat/energy.
- **Upgrade support:** existing 0.1–1.0 settings and receipts remain supported. Keep ProgramData\Lean81, including startup-backups, and LocalAppData\Lean81.

Windows security, networking, input, core services and Windows Update stay protected. Microsoft/system scheduled tasks remain inspection only. No blanket process killing, working-set trimming, registry cleaning, pagefile/kernel tweaks, driver removal or automatic uninstall is included.

The EXE is unsigned and targets Windows 8.1 / .NET Framework 4.5.1. Automated checks use newer Windows; physical Windows 8.1 testing remains pending. Native tests mutate only uniquely named disposable fixtures and their own compiled process, not real installed services, existing tasks or existing app processes. No speed increase is guaranteed without testing on the laptop.
